Перспектива выполнения · по категориям

Перспектива = (факт ÷ прошло дней × дней в периоде) ÷ план. Показывает ожидаемый % выполнения плана к концу периода при текущем темпе. Пунктир — линия 100%.

Перспектива рентабельности · по категориям

Факт рентабельности вводится в $ (сумма маржи), как и факт продаж — суммируется по иерархии категория/подкатегория/субкатегория/бренд. Перспектива рент. = проекция факта маржи по дням (та же формула, что и для продаж) ÷ план рент. в $ (план продаж × план рент.%).

Доля брендов · план по фильтру

Доля каждого бренда (в плане или по введённому факту продаж) в рамках текущего фильтра (сети/период/категория/подкатегория/субкатегория).

Share of Shelf · доля брендов на витринеEnter

Доля брендов на витрине (среднее по всем магазинам сети, взвешено по кол-ву мест). Показывается при выбранной категории, для которой внесены данные планограммы. Пока внесено: Enter · TV.

Ввод факта и отслеживание · категории

План (первый столбец таблицы) можно редактировать вручную на любом уровне — введённое значение становится абсолютным итогом для этого узла (приоритет над авто-расчётом), без правки — используется исходный план. Факт можно вводить на любом уровне (категория/подкатегория/субкатегория/бренд) — данные суммируются снизу вверх: бренды → субкатегория → подкатегория → категория. Если на верхнем уровне тоже введено значение и оно расходится с суммой по деталям — ячейка подсвечивается красным и выводится предупреждение выше. При выборе сразу нескольких сетей (напр. Enter + Ultra) план и факт суммируются по сетям, а ввод факта/плана становится доступен только при выборе одной сети (переключитесь на одну сеть, чтобы редактировать). Данные сохраняются в браузере; кнопками «⬇/⬆ Факт» можно выгрузить/загрузить их файлом; «⬇ Excel» — выгрузить таблицу План/Факт/% выполнения.
